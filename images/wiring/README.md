# images/wiring/ —— 硬件接线图上传区

本目录用于存放 W5 演示视频的硬件接线实拍图。

## 如何上传（Windows 用户网页直传）

1. 打开：https://github.com/ChuOZhen/MCPiano/tree/main/images/wiring
2. 点击右上角 **Add file → Upload files**
3. 把图片拖入，提交（Commit changes）即可

## 命名约定（与 README 引用对应）

| 建议文件名 | 内容 | README 引用 |
| --- | --- | --- |
| `wiring_breadboard.jpg` | 面包板按键 + LED 硬件直驱接线（10 键） | `images/wiring/wiring_breadboard.jpg` |
| `wiring_audio.jpg` | MAX98357A 功放接线 | `images/wiring/wiring_audio.jpg` |

> 若文件名不同，请同步更新 README「硬件接线图」小节的引用路径。
> 支持 jpg / png / jpeg。
