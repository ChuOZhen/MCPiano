## 1. 硬件平台概述

本项目的硬件平台是一块基于 **ESP32-D0WD-V3** 的通用开发板。与任务书描述的"固定开发板"不同，本项目使用的是**用户自购面包板搭建方案**，通过外接 LED、按键、蜂鸣器等外设完成数字钢琴功能。

### 1.1 核心芯片

| 器件 | 型号 | 功能 | 封装 |
|------|------|------|------|
| 主控 MCU | ESP32-D0WD-V3 | WiFi/蓝牙双核 240MHz MCU | QFN-48 |
| USB-UART | CP2102N-A02 | USB 转串口桥接 | QFN-28 |
| Flash | ZB25VQ32 | 32Mbit SPI Flash | SOP8 |
| 晶振 | 40MHz | 系统主时钟 | SMD 4P |

### 1.2 电源架构

```
USB 5V 输入 ──┬──► F1(500mA 保险丝) ──► D1(防反接) ──► U1(AMS1085-5V) ──► +5V
              │                                                              │
              └──► U3(AMS1085-3.3V) ──► VCC(3.3V) ──► ESP32 / 外设供电
```

| 器件 | 型号 | 输入 | 输出 | 电流 |
|------|------|------|------|------|
| U1 | AMS1085CM-5 | USB 5V | +5V | 1A |
| U3 | AMS1085CM-3.3V | +5V | 3.3V | 1A |
| F1 | FSMD050-1206 | — | — | 500mA 限流 |
| D1 | 1N4007 M7 | — | — | 反向保护 |

## 3. GPIO 映射表

### 3.1 数字钢琴使用 GPIO

| GPIO | 外设名称 | Designator | 方向 | 电平特性 | 驱动方式 | 用途 | 接线说明 |
|:----:|:---------|:-----------|:----:|:---------|:---------|:-----|:---------|
| **GPIO25** | 蜂鸣器 | B1 (外接) | 输出 | PWM | 直接驱动 | 音符发声 | GPIO25 → 蜂鸣器+ → 蜂鸣器- → GND |
| **GPIO32** | 绿色 LED | LED2 (外接) | 输出 | 低电平有效 | 330Ω 限流 | 状态/视觉反馈 | 3.3V → 330Ω → LED+ → LED- → GPIO32 |
| **GPIO33** | 红色 LED | LED3 (外接) | 输出 | 低电平有效 | 330Ω 限流 | 状态/视觉反馈 | 3.3V → 330Ω → LED+ → LED- → GPIO33 |
| **GPIO34** | KEY1 按键 | K3 (外接) | 输入 | 内部上拉 | 直接连接 | 钢琴键 1 | GPIO34 → 按键 → GND |

| GPIO3 | U0RXD | — | 输入 | — | 内部 | 串口 RX | CP2102N 自动连接 |

## 4. 模块功能分析

### 4.1 电源模块

| 项目 | 内容 |
|------|------|
| **器件** | U1(AMS1085-5V), U3(AMS1085-3.3V), F1, D1 |
| **功能** | USB 5V → 5V LDO 稳压 → 3.3V LDO 稳压 → 系统供电 |
| **保护** | F1 限流 500mA，D1 防反接 |
| **钢琴作用** | 为 ESP32 及全部外设供电 |

### 4.2 USB 编程模块

| 项目 | 内容 |
|------|------|
| **器件** | CP2102N(U2), Q1/Q2(MMSS8050), R1/R2/R4 |
| **功能** | USB 转 UART，支持自动下载 |
| **自动下载** | Q1(DTR) + Q2(RTS) 控制 BOOT 和 RESET |
| **钢琴作用** | 固件烧录、REPL 调试、串口监控 |
| **波特率** | 115200（默认） |

### 4.3 微控制器核心

| 项目 | 内容 |
|------|------|
| **器件** | ESP32-D0WD-V3(U4), ZB25VQ32(U5), 40MHz(X1) |
| **功能** | 双核 240MHz MCU，集成 WiFi/蓝牙，32Mbit Flash |
| **启动** | R5(20k) 为 EN 上拉，确保正常启动 |
| **钢琴作用** | 运行 MicroPython 固件，控制全部外设 |

### 4.4 蜂鸣器发声模块

| 项目 | 内容 |
|------|------|
| **器件** | 外接蜂鸣器（用户自购） |
| **GPIO** | GPIO25 |
| **驱动** | PWM 方波驱动 |
| **接线** | GPIO25 → 蜂鸣器+ → 蜂鸣器- → GND |
| **钢琴作用** | 播放 do-re-mi-fa-sol-la-si 音阶 |
| **注意** | 通用开发板无板载蜂鸣器，需面包板外接 |

### 4.5 LED 指示模块

| 项目 | 内容 |
|------|------|
| **器件** | 外接 5mm LED（用户自购） |
| **GPIO** | GPIO32(绿), GPIO33(红) |
| **电平** | 低电平有效（0=亮，1=灭） |
| **限流** | 330Ω 电阻 |
| **接线** | 3.3V → 330Ω → LED+ → LED- → GPIO |
| **钢琴作用** | 按键反馈、状态指示 |

### 4.6 按键输入模块

| 项目 | 内容 |
|------|------|
| **器件** | 外接 6×6×5mm 按键（用户自购） |
| **GPIO** | GPIO34(KEY1), GPIO35(KEY2) |
| **电平** | 内部上拉，按下=低电平(0) |
| **接线** | GPIO → 按键 → GND |
| **钢琴作用** | 钢琴键输入，触发音符播放 |
| **注意** | 软件需去抖处理（10-20ms） |

### 5.2 闲置资源（不启用及理由）

| 资源类型 | GPIO/接口 | 器件 | 不启用理由 |
|:---------|:---------|:-----|:-----------|
| 按键 | GPIO0 | K1 (BOOT) | 系统保留，用于固件下载 |
| 按键 | CHIP_PU | K2 (RESET) | 系统保留，用于硬件复位 |

### 5.3 扩展功能预留（可选）

| 扩展功能 | 所需资源 | 实现难度 | 优先级 |
|:---------|:---------|:---------|:------:|
| 八度切换 | KEY1+KEY2 组合按键 | ⭐⭐ | 高 |
| 旋律录制/回放 | LED 状态 + 列表存储 | ⭐⭐⭐ | 高 |
| 启动动画 | LED2+LED3 + 蜂鸣器 | ⭐⭐ | 中 |
| OLED 显示 | GPIO16/17 (I2C) + SSD1306 | ⭐⭐⭐ | 中 |
| 更多按键 | GPIO 排针 + 外接按键 | ⭐⭐ | 中 |
| I2S 音频 | GPIO25/26/27 + MAX98357A | ⭐⭐⭐⭐ | 低 |

## 7. 硬件约束清单

- [x] **蜂鸣器**：GPIO25 PWM 输出，duty=512 发声，duty=0 静音
- [x] **LED**：低电平有效，GPIO=0 点亮，GPIO=1 熄灭
- [x] **按键**：内部上拉，按下读数为 0，释放读数为 1
- [x] **固件**：MicroPython（ESP32-D0WD-V3）
- [x] **USB-UART**：CP2102N，波特率 115200
- [x] **GPIO6-11**：被 SPI Flash 占用，**不可使用**
- [x] **外接方案**：通用开发板无板载外设，全部通过面包板外接
